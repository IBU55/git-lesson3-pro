# Отчёт по заданию «Git Lesson 3 Pro»

Ниже перечислены этапы выполнения задания и скриншоты, подтверждающие каждый пункт. Скриншоты находятся в корне задания в папке `screenshot3_otchet`.

| № | Требование | Что сделано | Скриншоты |
| - | ---------- | ----------- | -------- |
| 1 | Настроить запрет прямых merge в `main` | Создан ruleset «Protect main»: разрешены только PR, включен запрет на создание/обновление/удаление ветки без прав, требуются 2 одобрения и прохождение проверок. | `screenshot3_otchet/Снимок экрана 2026-01-20 в 18.04.50.png`, `screenshot3_otchet/Снимок экрана 2026-01-20 в 18.23.09.png` |
| 2 | Требовать approvals для merge в `develop` | Все PR, идущие в `develop`, проходят через обязательное ревью Copilot. На скринах видно требование «At least 1 approving review is required». | `screenshot3_otchet/Снимок экрана 2026-01-20 в 23.29.28.png` (PR #5), `screenshot3_otchet/Снимок экрана 2026-01-21 в 00.57.23.png` и `...01.39.45.png` (PR #7 и #9) |
| 3 | Создать несколько issues | Созданы issues: #1 «Добавление README», #2 «создать файл .gitignore», #3 «добавить файл LICENSE». | `screenshot3_otchet/Снимок экрана 2026-01-20 в 23.43.15.png`, `screenshot3_otchet/Снимок экрана 2026-01-21 в 01.04.59.png`, `screenshot3_otchet/Снимок экрана 2026-01-21 в 01.33.37.png` |
| 4 | Работать по каждой issue в отдельной ветке | Для каждой задачи создана отдельная ветка и привязка issue→branch. На странице веток видно `feature/issue-1-readme`, `feature/issue-2-gitignore`, `feature-issue3-add-LICENCE-file`. | `screenshot3_otchet/Снимок экрана 2026-01-21 в 00.20.27.png`, `screenshot3_otchet/Снимок экрана 2026-01-21 в 01.16.27.png` |
| 5 | Слить изменения в `develop` | Все рабочие ветки смёржены в `develop` через Pull Request. На скринах PR #5, #7, #9 статус `Merged` и строка «IBU55 merged commit ... into develop». | `screenshot3_otchet/Снимок экрана 2026-01-21 в 00.58.42.png` (PR #7), `screenshot3_otchet/Снимок экрана 2026-01-21 в 01.39.45.png` (PR #9) |

**Дополнительно**
- `screenshot3_otchet/Снимок экрана 2026-01-21 в 01.22.42.png` показывает актуальное состояние ветки `feature-issue3-add-LICENCE-file` и файлы `.gitignore`, `LICENSE`, `README.md`.
